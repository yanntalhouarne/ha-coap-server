              only for flashing new boards over SWD.

          Settings
          
          
          
            
          
          
          
        
          
        
          
          
          Notifications and app updates
          
          
          
            
          Browser notifications
          
            
          Alerts (a device stops answering, a low battery, a plant that needs
              water, a failed update) can pop up as notifications while this page is open, even in a background tab.
          
            
          
              
              
            
          
            
          App updates
          
            
          With Check GitHub for app updates on (above), the app asks
              GitHub once a day whether a newer fleet manager is out, and says so in the status bar. Nothing else is sent.
          
            
          
              
              
            
          
          
          
        
          
        
          
          
          Running in the background
          
          
          
            
          History, alerts and network readings only build up while the app
              runs. Started with the computer, it runs in the background, without a window: open
               (bookmark it) to see it. Starting the app again also opens it.
          
            
          
              
              
            
          
            
          
            
            
          Stops collecting until it starts again. It waits for an update, build or setup step to finish.
          
          
          
        
          
        
          
          
          Try the demo
          
          
          
            
          Opens a second fleet manager, in a new tab, with 9 simulated
              boards, a simulated border router and two weeks of made-up history: every page has something to show.
              It uses its own data folder, deleted when it stops, so your fleet isn't touched.
          
            
          
          
        
          
        
          
          
          Home Assistant history
          
          
          
            
          Home Assistant already has your boards' readings from before the app
              ran. With its address and a long-lived access token (in Home Assistant: your profile, Security tab,
              Long-lived access tokens), the app imports them into its charts. Boards are matched by their device-id
              sensor. Home Assistant keeps 10 days of history by default.
          
            
          
              
          
                
                
              
          
              
          
                
                
              
          
              
          
                
                
                
              
          
            
          
            
          
            
          
              
              
              
            
          
            
          The token stays in its own file in the data folder: never in backups, problem reports or
              this page. Importing twice adds nothing new.
          
          
          
        
          
      
          
      
          
        
          
          
          About
          
          
          
        
          
        
          
          
          Data
          
          
          
            
          Space used
          
            
          
            
          
              
              
            
          
            
          How long readings and network history are kept is set under Settings (Keep
              readings, Keep network readings, Keep backups). Old data is deleted once a day; compacting gives the space
              back to the disk.
          
            
          Backup
          
            
          One file with everything: devices, images, update history, build profiles
              and settings. Use it to keep a copy, or to move the app to another PC.
          
            
          
              Download a backup
            
          
            
          
              
              
            
          
            
          Restoring replaces all the app's data with the backup's. The current data is
              saved as a backup first.
          
            
          Saved backups
          
            
          A backup is made automatically once a day while the app runs
              (the last 7 are kept, see Settings), and before every restore.
          
            
            
            
            Device list
            
            
            A spreadsheet (CSV) of the devices. Importing one adds or updates devices
              by their device ID: name, address and notes; the rest comes from the devices.
            
            
            
              Export devices (CSV)
            
            
            
            
              
              
            
            
            
            Readings
            
            
            Every reading the app stored (battery, soil, air, temperature), for
              every device, as a spreadsheet (CSV). Each device's page has its own.
            
            Export readings (CSV)
            
            Problem report
            
            
            One file with the app's recent log, settings, devices, update and build
              history and the last network reading, to look into a problem or attach to an issue. It holds no signing
              key and no PSKd (it's blanked out of the logs).
